**Hello world!** 👋

This is your first post, rendered from MDX through an Astro content collection.

## What is under the hood

- **Astro** — static site generation, HTML by default
- **React** — small interactive islands (theme toggle, mobile nav)
- **MDX** — Markdown plus inline components
- **Tailwind CSS** — utility-first styling
- **Cloudflare Pages** — cheap static hosting

## Editing this post

Open `src/content/blog/hello-world.mdx`, edit the frontmatter, and write. A new file in that
folder becomes a new post automatically.
